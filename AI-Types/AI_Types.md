What is Artificial Intelligence:
Artificial intelligence is a computer science that enables machines to perform human tasks which requires human intelligence. Such as Understanding language and making decisions, learning from data and generating new content in text, images and videos

Overview on Types of AI:

Computer Vision

    Image Classification:
        o	Helps to identify the object in images. Example:  Detecting specific brand in an image
    
    Object Detection: 
        o	Helps to locate objects with their X & Y coordinates and along with confident score.
        o	Powers autonomous vehicles to recognise pedestrians and other vehicles using bounding boxes
    
    Semantic Segmentation: 
        o	 Assigns a label to every pixel in an image, allowing for precise delineation of different objects or regions
        o	Majorly used in the medical imaging , for instance while diagnosing a tumour pixel by pixel
    
    Optical Character Recognition: 
        o	Helps to extract and read the text from image, to digitalize the printed or handwritten content
    
    Facial Detection:
        o	 Identifies human faces in images and analyse facial features. Group similar faces by drawing bounding box on faces. 
        o	Widely used in Security features such as unlocking devices through facial features

GEN AI: 

They are designed to generate new content across multiple formats. Such as Text (Copilot), Images (DALL-E), Videos (Synthesia) and NLMs are subset of GEN-AI

Model such as : GPT-5, text-embedding-model

Some of Techniques:

Transformers: Powerful models for processing sequences of data, critical in modern language and image generation.

GAN (Generative Adversarial Networks) : Used to generate the highly realistic synthetic data such as images

VAE – Variational Auto Encoders: Used to detect Anomalies such as Financial frauds, Manufacturing frauds, Health care Anomalies and are trained on huge amount of data sets

Natural Language Process:
It is focused on the interaction between AI-System and human,  where AI systems can understand and interpret human language. 

    Natural Language Models:
    Models are developed to interact with humans in a natural spoken language, these models are trained with huge amount of data to perform the below activities.
    •	Content Generation 
    •	Text Summarization
    •	Conversational Agents 
    •	Translation
    •	Creative writings
    
    Natural Language Processing Tasks:
    Designed to provide response to users inputs or queries by retrieving information from the knowledge base.
        It understands the intent behind the input query based on below entities

            List: Used to identify a set of predefined values in text
            Regular Expression: Patter used to match character combination text
           Machine learning: Typically used for more complex pattern.

        This is used in:
            Sentiment Analysis
            Topic Detection
            Language Detection
            Key Phrase Extraction 
            Document Categorization
        Example is : Azure Language Services
