Large Language Models: 
LLMs are AI systems which are trained on massive amount of data, to understand human queries and generate responses based on probability.
LLMs requires human oversight to validate responses and prioritize most accurate and reliable one. 
LLMs are defined has probability machines and they work by predecting the next token based on previous one

Model Examples:

    OpenAI: Company that creates ChatGPT and other language models


Tokenizer: Process of spliting text into smaller chunks or tokens and assigning each one number

Encoding : Converting text tokens into numeric

Fine Tuning:Further pre-training the LLMs on more specific data to adopt it to particular task

Retrieval Augument Generation : 

    1.A techinque in AI where LLM access new or more recent data outside its training set to provide better and accurate response

Repurposing : Using a base model for a task different than its original purpose.


Building Robust GEN AI Systems:

API based applications:  An application that interact with s/w components using application program interface (API) for data exchange, communication or functional enhancement.

Embedded Model: A Machine Learning (ML) model integrated with an application allowing app to perform specific task without relying on external services.

Multi Model App: An AI system that utilize multiple models tailored to different functions or domain improving effeciency and performance in various scenarios.

HTTP API:  An interface for exchasing data between systems using Hyper text transfer protocol (HTTP) request and response over internet
