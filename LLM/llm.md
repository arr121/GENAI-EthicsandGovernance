**Large Language Models:**

LLMs are AI systems which are trained on massive amount of data, they understand and interpret human queries and generate responses in human understanding language.

Key Characteristics
- Trained on huge corpora of text and code
- Generate responses based on probability, not guaranteed truth
- Require human oversight to validate accuracy and reliability
- Excel at reasoning, summarization, translation, Q&A, and content generation
- Can hallucinate, making governance and validation essential


**Model Examples:**

- OpenAI:ChatGPT
- Google Brand: Gemini,Meta Llama 
- Anthropic : Claude


Tokenizer: Process of spliting text into smaller chunks or tokens and assigning each numeric ID

Encoding : Converting text tokens into numeric vectors that model can process

Fine Tuning:Further pre-training the LLMs on more domain specific data to adopt it to specialized tasks

Retrieval Augument Generation : 
A techinque in AI where LLM retrieves new or more recent data from external resources to provide better and accurate response

Repurposing : Using a base model for a task different than its original purpose.


**Building Robust GEN AI Systems:**

API based applications:  An application that interact with s/w components using application program interface (API) for data exchange, communication or functional enhancement.

Embedded Model: A Machine Learning (ML) model integrated with an application allowing app to perform specific task without relying on external services.

Multi Model App: An AI system that utilize multiple models tailored to different functions or domain improving effeciency and performance in various scenarios.

HTTP API:  An interface for exchasing data between systems using Hyper text transfer protocol (HTTP) request and response over internet
